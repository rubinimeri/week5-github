# week5-github

## Todo App

This a terminal based todo app made entirely in C, you can see your todos, create new ones, delete existing ones etc.

### Files

- todo-app.c
- tasks.c
- tasks.h

### How to run

```bash
gcc -Wall -o todo todo-app.c tasks.c
./todo
```
